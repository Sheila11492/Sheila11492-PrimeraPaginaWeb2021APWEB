🌍 Primera Página Web – Playa y Montaña

Este proyecto corresponde a **mi primera página web**, desarrollada durante el **primer curso del Grado Medio de Sistemas Microinformáticos y Redes (SMR)**, en la asignatura **Aplicaciones Web**.

Se trata de una web sencilla cuyo objetivo es mostrar **sitios turísticos de playa y montaña**, aplicando los conocimientos básicos de HTML y CSS adquiridos en clase.

---

## 🏫 Contexto académico

- 📚 Ciclo: Sistemas Microinformáticos y Redes (SMR)
- 🧑‍🎓 Curso: 1º
- 📘 Asignatura: Aplicaciones Web
- 🎯 Tipo de proyecto: Práctica educativa / aprendizaje inicial

---

## 🖥️ Descripción del proyecto

La página web presenta diferentes lugares que se pueden visitar, clasificados en:
- 🏖️ **Zonas de playa**
- ⛰️ **Zonas de montaña**

Cada sección incluye información básica y elementos visuales para practicar la estructura de una página web y la organización del contenido.

---

## 🛠️ Tecnologías utilizadas

- **HTML5**
- **CSS3**
- Plantilla **W3.CSS** (para el diseño y estilos)
